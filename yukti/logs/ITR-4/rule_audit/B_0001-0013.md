# ITR-4 · Category B rules 1–13 — enforcement audit
read-only · opus auditor

Category B = CBDT "may be treated as defective u/s 139(9)" — advisory. There is no `B()` collector
in the engine (confirmed: `runRules` in 60_rules.js only exposes `A`/`Dd`, and grepping `B\(n,`
across 60_rules.js + 61_rules_g*.js returns nothing). Each serial is therefore judged on whether the
software enforces it anyway, enforces it by construction, cannot enforce it (portal/DB/AIS-only), or
leaves a genuine gap.
