# ITR-3 · Category B rules 1–40 — enforcement audit
read-only · opus auditor

Category B ("may be treated as defective u/s 139(9)") has no `B()` call in the engine — there is none anywhere in `60_rules.js` / `61_rules_g*.js`. Each serial is judged on whether its concept is enforced anyway (via an `A()`/`Dd()` call or by construction), is inherently unenforceable offline (external-form reconciliation / 26AS / portal-side linking → informational, NA), or is a genuine hole (GAP). The engine does encode a family of "must also file Form X" advisory notices as **Category D** `Dd()` calls (Dd1/3/5/6/10/11/13/14) — where a B rule's Form-X notice is missing from that family it is flagged GAP for consistency.
