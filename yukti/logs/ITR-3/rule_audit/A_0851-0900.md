# ITR-3 · Category A rules 851–900 — enforcement audit
read-only · opus auditor

Structural context: Schedule SI is an auto-computed table (`engSi`, 70_sec_si.js). Only the capital-gains
heads are auto-populated from Schedule CG buckets; the OS / DTAA / PTI / non-resident heads are entered
**manually** through the "edit auto-populated details" override (`S.si.rows`). SI is therefore **not**
cross-checked against Schedule OS / BP / BFLA line items — except the single explicit A(852). Every CBDT rule
that asserts "SI head X = OS/BP/BFLA item Y" that lacks its own A() call is a genuine hole (a manual SI entry
can diverge from the source and nothing catches it).
