read-only · opus auditor

Context: Schedule CG arithmetic (deduction/balance totals) is auto-computed by the engine
(`engLand`/`engAgg`/`engSlump`/`engScrip` in `70_sec_cg.js`) into green, untypeable cells and written to the
export by construction; such totals are STRUCT when no `A()` re-verifies them. Table E set-off caps and Table F
quarter tallies are only structurally safe on the *default* path — the `editE`/`editF` override switches
(`70_sec_cg.js:326`, `:344`) let a user type arbitrary values, so unguarded caps there are real GAPs.
