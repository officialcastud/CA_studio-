# Sheet 80 — Profit-linked deductions u/s 80-IA / 80-IB / 80-IC(IE)

Form: **ITR-5**, A.Y. 2026-27. Sheet: **80** (`sheet34.xml`, visible, 131 rows, 50 hidden). Section: `ded`.
Blocks: **Schedule80_IA**, **Schedule80_IB**, **Schedule80_IC**.
Source: `python tools/dump.py --form ITR-5 --sheet "80"` (rows / --formulas / --dropdowns) and `--schema` / `--leaves` for each of `Schedule80_IA`, `Schedule80_IB`, `Schedule80_IC`; named-range → cell map from `sources/ITR-5/utility/xl/workbook.xml`; fixed section/location codes from `sources/ITR-5/vba_text.txt`; rules from `books/ITR-5/rules.json`.

## The shape

Sheet 80 is three stacked schedules on one sheet:

- **Schedule 80-IA** (rows 4-25) — header `[C4]` "Schedule 80-IA", `[F4]` "Deductions under section 80-IA". Five deduction clauses (a-e), of which **only two are visible** (Infrastructure 80-IA(4)(i) and Power 80-IA(4)(iv)); the other three are hidden. A total row `[C25]` c.
- **Schedule 80-IB** (rows 27-76) — header `[C27]` "Schedule 80-IB", `[F27]` "Deductions under section 80-IB". Twelve deduction clauses, of which **only five are visible** (J&K/Ladakh, mineral oil, housing, fruit/veg, foodgrains); the other seven are hidden. A total row `[C76]` f.
- **Schedule 80-IE** (rows 78-127) — header `[C78]` "Schedule 80-IE", `[F78]` "Deductions under section 80-IE". Three location clauses a/b/c (Sikkim, Himachal, Uttaranchal) are **hidden**; the **North-East block** `[D92]` A (eight state sub-rows Aa-Ah, rows 93-121) is **visible**, plus its subtotal `[E125]` Ai and the schedule total `[C127]` B. This whole schedule maps to schema block **Schedule80_IC**.

Within every clause the pattern is identical: a printed clause label row, then **two "Undertaking" input rows** (Undertaking 1, Undertaking 2), each carrying one amount. The amount is entered in column **H**; the "Undertaking N" caption in column F (IA/IB) or column G (IE) is auto-built by `CONCATENATE("Undertaking ",…)`. Each clause therefore corresponds to one schema object whose `Sch80DeductAmtDtls` array holds up to two `DeductAmountSec80` amounts, and whose `Sch80LocOrDescCode` is a **fixed constant** (never a user input — see below).

Note `[C3]` (verbatim): *"(Note: If no entry is made in first row then other rows will not be considered)"* — i.e. Undertaking 2's amount is ignored unless Undertaking 1 has a value.

## The rules the sheet computes (with cell references)

All four totals share a guard: **zero when the return is filed u/s 12 (`MID(sheet1.ReturnFileSec,1,2)="12"`) or when the new tax regime is opted (`bacValue=1`)**; otherwise a SUM of the clause named-ranges.

- **80-IA total** `[H25]= IF(MID(sheet1.ReturnFileSec,1,2)="12",0,IF(bacValue=1,0,SUM(IA80.DeductProfUs80_IA_4_io,IA80.DeductProfUs80_IA_4_i,IA80.DeductProfUs80_IA_4_ii,IA80.DeductProfUs80_IA_4_iii,IA80.DeductProfUs80_IA_4_iv)))` → `TotSchedule80_IA` = sum of all clause amounts (visible + hidden). rules.json **A624**: *"In \"Schedule 80-IA\" Total deductions under section 80-IA should be equal to the value entered in (a + b)"*.
- **80-IB total** `[H76]= IF(…="12",0,IF(bacValue=1,0,SUM(IB80.DeductJKLocUs80_IB_4,IB80.DeductBackStatesUs80_IB_4,IB80.DeductBackDisttUs80_IB_5,IB80.DeductMultiplexUs80_IB_7A,IB80.DeductConvCentUs80_IB_7B,IB80.DeductMinOilUs80_IB_9,IB80.DeductHousUs80_IB_10,IB80.DeductColdChainUs80_IB_11,IB80.DeductFruitVegUs80_IB_11A,IB80.DeductFoodGrainUs80_IB_11A,IB80.DeductRurHospUs80_IB_11B,IB80.DeductHospAnyAreaUs80IB_11C)))` → `TotSchedule80_IB`. rules.json **A625**: *"Total of Schedule 80-IB in Sl.No. f should be equal to sum of all individual line items i.e (Total of a to e )"*.
- **North-East subtotal** `[H125]= IF(…="12",0,IF(bacValue=1,0,SUM(IC80.Assam,IC80.ArunachalPradesh,IC80.Manipur,IC80.Mizoram,IC80.Meghalaya,IC80.Nagaland,IC80.Tripura,IC80.Sikkim)))` → `DeductInNorthEast.TotDeductInNorthEast`. rules.json **A627**: *"Schedule 80IE sl. no ai should be equal to sum of sl. no. aa to ah"*.
- **80-IE total** `[H127]= IF(…="12",0,IF(bacValue=1,0,SUM(IC80.TotDeductInNorthEast,IC80.DeductInUttaranchal,IC80.DeductInHimachalP,IC80.DeductInSikkim)))` → `TotSchedule80_IC` = North-East subtotal + the three hidden location clauses. rules.json **A626**: *"Schedule 80IE Sl.No. b should be equal to. ai"* (with only North-East visible, B = Ai).
- **`Sch80LocOrDescCode` is not a user input** — it is a fixed per-clause constant emitted by the VBA export (e.g. `INFRAFAC`, `POWER`, `INDSRTL_JK`, `COMM_PROD`, `HOUSING_PROJECT`, `FRIUTS_VEGTBLE`, `STOR_TRANS`, `INDSRTL_ASSAM` …). `Sch80SectionCode` is likewise fixed per block (`80-IA`, `80-IB`, `80-IC_IE`).
- **"Undertaking N" captions** are computed: `[F7]= CONCATENATE("Undertaking ",E7)`, `[E8]= E7+1`, `[F8]= CONCATENATE("Undertaking ",E8)` — the pattern repeats for every clause (F/E columns in IA/IB, G/F columns in the North-East rows).

### Cross-schedule rules (from rules.json)
- **A633 / (3220)**: value claimed in 80-IA field in Schedule VI-A at Sl.No. 2d cannot exceed `TotSchedule80_IA` (Sl.No c). **A634 / (3225)**: if 80-IA claimed in VI-A but Schedule 80-IA not filled → error.
- **A636 / (3230)**: value claimed in 80-IB in VI-A cannot exceed `TotSchedule80_IB`. **A637 / (3235)**: 80-IB claimed in VI-A but Schedule 80-IB not filled → error.
- **A639 / (3240)**: value claimed in 80IE in VI-A cannot exceed `TotSchedule80_IC`.
- **A628**: *"Deduction u/s 80IB in Sl.no.2g cannot be more than non speculative and non specified business income and non presumptive income in Schedule VIA."* **A629**: same cap for 80IE (Sl.no.2i).
- Category B/D (rules.json ~4440): deduction u/s 80-IA(7)/80-IB/80-IC/80-IE can be claimed only if **Form 10CCB** is filed.

## Dropdowns

`python tools/dump.py --form ITR-5 --dropdowns "80"` returns only numeric-input constraints (`source: "0"`, `values: null`) on the amount cells — e.g. `H7:H8`, `H11:H12`, `H15:H16`, `H19:H20`, `H23:H24`, `H30:H31`, `H34:H35`, … `H122:H123`, plus the label/first cells `G30 G34 … G89`. **There are no value-list dropdowns on this sheet** — every input is a plain integer amount (≥ 0). Nothing to enumerate.

## What repeats and what is one figure

- **Per clause, exactly two undertaking amounts** (`Sch80DeductAmtDtls` array, max 2 entries: Undertaking 1 = first cell, Undertaking 2 = second cell). Not an open add-row list — the two rows are fixed. Undertaking 2 is ignored if Undertaking 1 is blank (`[C3]` note).
- **The clause list itself does not repeat**: IA has two fixed visible clauses, IB five, IC eight North-East states — each a distinct named schema object.
- **One figure each:** `Sch80LocOrDescCode` (fixed constant), and each total (`TotSchedule80_IA`, `TotSchedule80_IB`, `DeductInNorthEast.TotDeductInNorthEast`, `TotSchedule80_IC`) is a single computed figure.

## Mandatory

Schema `required`:
- **Schedule80_IA**: `Sch80SectionCode`, `DeductUs80_IA_4_i`, `DeductUs80_IA_4_iv`, `TotSchedule80_IA`. Within each clause object: `Sch80LocOrDescCode` and (per array element) `DeductAmountSec80` are required.
- **Schedule80_IB**: `Sch80SectionCode`, `DeductJKLocUs80_IB_4_Und`, `DeductMinOilUs80_IB_9_Und`, `DeductHousUs80_IB_10_Und`, `DeductFruitVegUs80_IB_11A_Und`, `DeductFoodGrainUs80_IB_11A_Und`, `TotSchedule80_IB`. Within each clause: `Sch80LocOrDescCode`, `DeductAmountSec80` required.
- **Schedule80_IC**: `Sch80SectionCode`, `DeductInNorthEast`, `TotSchedule80_IC`. Within `DeductInNorthEast`: all eight state sub-objects (`Assam_Und`, `ArunachalPradesh_Und`, `Manipur_Und`, `Mizoram_Und`, `Meghalaya_Und`, `Nagaland_Und`, `Tripura_Und`, `Sikkim_Und`) + `TotDeductInNorthEast` required; within each state: `Sch80LocOrDescCode`, `DeductAmountSec80` required.

In practice the whole sheet 80 is optional data — build it only when a profit-linked deduction is claimed; once a block is built, the required structure above must be present. Totals go to zero under the new regime (`bacValue=1`) or a s.12 return.

## What this means for the build

- Build three schema blocks. **Schedule80_IA** = 2 visible clauses (Infrastructure `DeductUs80_IA_4_i`, Power `DeductUs80_IA_4_iv`), each with a fixed `Sch80LocOrDescCode` and a `Sch80DeductAmtDtls` array of up to 2 `DeductAmountSec80` amounts; `TotSchedule80_IA` computed. **Schedule80_IB** = 5 visible clauses, same pattern. **Schedule80_IC** = the North-East block only: `DeductInNorthEast` with 8 state sub-objects + `TotDeductInNorthEast`, and `TotSchedule80_IC`.
- Emit `Sch80SectionCode` as the fixed constant per block (`80-IA` / `80-IB` / `80-IC_IE`) and `Sch80LocOrDescCode` as the fixed per-clause constant listed above — **these are not inputs**.
- Only the amount cells (column H, two per clause) are user inputs; each is an integer ≥ 0. Undertaking 2 is written only if Undertaking 1 is present.
- Totals: `TotSchedule80_IA` = Σ IA clauses; `TotSchedule80_IB` = Σ IB clauses; `TotDeductInNorthEast` = Σ eight states; `TotSchedule80_IC` = `TotDeductInNorthEast` (the three 80-IE location clauses are hidden/0). All four zero out when `bacValue=1` (new regime) or a s.12 return.
- Do **not** build any hidden clause (telecom, industrial park, revival power, backward states/districts, multiplex, convention centre, cold chain, rural hospital, hospital-any-area, 80-IE Sikkim/Himachal/Uttaranchal) — none is in the exposed schema.
- Cross-links: `TotSchedule80_IA`/`_IB`/`_IC` cap the corresponding VI-A deduction fields (2d/80-IB/80IE); Form 10CCB is a filing precondition.
