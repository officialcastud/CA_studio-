# ITR-5 — the structure (the continuous sheet)

Eighteen sections, ordered by how often a filer needs them. ITR-5 is for firms / LLPs / AOPs / BOIs / AJPs /
business trusts / investment funds — the full business stack (Balance Sheet, P&L, Manufacturing/Trading accounts,
Schedule BP, depreciation, ESR, ICDS, GST, capital gains with slump-sale, the CYLA/BFLA/CFL loss chain plus
unabsorbed depreciation, AMT, partners'/members' information, pass-through income). One sheet, a left index that
scrolls to a section, collapse-and-open at every level.

## Hidden sheets — built (why_built) or excluded (reason)

`Tax` is the only hidden sheet mapped to a section: it is the live tax-computation method behind Part B-TTI
(referenced by 123 defined names such as `TaxPayableOnTotInc`, `SurchargeOnTaxPayable`, `EducationCess`). It is read
to derive the tax engine, never displayed.

Every other hidden sheet is excluded — see `section_map.json` for the exact reason on each:

- **Part A Gen_139(8A)**, **Part B ATI** — the ITR-U updated-return flow (section 139(8A)); a separate return type.
- **Tax(N)** — a superseded/unused alternate tax-computation sheet (0 defined-name references; `Tax` is live).
- **DB** — the master dropdown/enum database backing every (Select) list (124k rows); a data source, not a screen.
- **FD** — Schedule FD (foreign-currency break-up) has no schema block in ITR-5 (`ScheduleFD` absent) — cannot be filed.
- **PDTCAse** — reference case-flag lookup table feeding the hidden `Tax` sheet; not a screen.
- **CG Pop up_prefill** — AIS prefill pop-up staging table for capital-gains data; an import helper.
- **112**, **115** — CSV import staging tables (ISIN rows) for Schedules 112A / 115AD; data-entry helpers.
- **Instructions**, **HelpCSV**, **Help** — help/instruction pages, not part of the return.
- **SUMMARY** — a print/summary display view computed from the other sheets; no input, no schema block.
